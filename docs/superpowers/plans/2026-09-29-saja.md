# ‘뭐 사야 하지?’ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 혼자 쓰는 오프라인 장보기·위시리스트 PWA를 구현하고 브라우저에서 확인한다.

**Architecture:** 프레임워크 없는 정적 웹앱. 순수 데이터 함수(`core.js`), IndexedDB 저장소(`store.js`), DOM 인터랙션(`app.js`)을 분리한다. 서비스 워커는 앱 셸만 캐시하고 사용자 기록은 IndexedDB에 둔다.

**Tech Stack:** HTML, CSS, JavaScript, Node 내장 테스트 러너, Playwright 브라우저 검증(가능할 때).

**Spec:** `docs/superpowers/specs/2026-09-29-saja-design.md`

## Global Constraints

- 첫 버전은 계정·서버·가격비교·외부 쇼핑몰 연동·알림 없음.
- 필수 입력은 이름만; 저장 버튼 없음; 다른 1~4호 프로젝트 건드리지 않음.
- 데이터는 로컬 IndexedDB, 백업은 버전 붙은 JSON; 기본 병합에서 기존 ID 보존, 전체 교체는 별도 확인.
