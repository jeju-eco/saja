# 뭐 사야 하지? (5호)

혼자 쓰는 장보기·위시리스트 PWA입니다. **사야 하지 / 사고 싶지 / 샀음** 목록에 물건 이름만 입력하면 즉시 기기에 저장됩니다. 구매 후 이전 목록으로 되돌리거나 두 목록 사이를 옮길 수 있습니다. 가격·링크·메모는 선택 사항입니다.

## 실행

정적 파일을 HTTPS로 서빙하면 폰에서 홈 화면에 추가할 수 있습니다. 로컬 확인: `python -m http.server 8779` 후 `http://localhost:8779/`. 첫 방문과 업데이트에는 인터넷이 필요할 수 있으며 이후에는 앱 셸이 오프라인으로 캐시됩니다.

## 데이터와 백업

계정과 서버가 없습니다. 이 브라우저의 IndexedDB에만 저장되므로 다른 기기·브라우저와 자동 동기화하지 않습니다. 브라우저 데이터 삭제 시 백업 파일이 없으면 복구할 수 없습니다. **백업 내려받기**는 JSON v1, **백업 복원**은 형식 검증 후 병합 또는 전체 교체를 확인받습니다. 기존 ID는 병합에서 보존합니다. 전체 교체는 현재 목록을 지웁니다.

## 검증

`npm ci && npm test` — 규칙·백업·화면 상호작용 테스트. 브라우저에서 추가·이동·구매·되돌리기·새로고침·오프라인 재실행을 별도로 확인해야 합니다.
